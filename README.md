# 小菇爱评论

给**腾讯视频**自动发评论的工具,自己用的。

多个号可以同时跑:每个号一个独立的数据仓和悬浮窗,评论内容从远程评论池拉。

> ⚠️ 这是自用工具,不是产品 —— 没有客服,也不保证适合你的用法。

## 怎么装

1. 下载 `qq-comment.apk`。
2. 点开装。系统会问「要不要允许从这个来源安装」—— 允许。
   (这是 Android 对所有非商店应用的统一提示,不是这个 App 特别要什么权限。)
3. 第一次启动后,`账号` 页顶上有一块「**开始之前**」,跟着它开**悬浮窗**权限。
   这是**唯一**一个要你自己去系统里开的权限。

   ⚠️ **那个开关是灰的、点了弹「已拒绝访问」?** 安卓 13 起对「不是从应用商店装的
   App」多了一道闸,先解开它:**系统设置 → 应用 → 小菇爱评论 → 右上角那三个点 →
   允许受限设置**,再回去开那个开关。安卓对所有侧载应用都这样,不是这个 App 特别要什么。
4. **顺手把省电也放行了**:**系统设置 → 应用 → 小菇爱评论 → 电池 → 不优化 / 无限制**。
   国产 ROM 上通常还有一处:**设置 → 电池 → 后台耗电管理 / 应用启动管理 →
   允许自启动、允许后台活动**。

   不放行的话,**屏幕关久了系统会把它的心跳停掉** —— 有人的手机中间停过 **47 分钟**,
   那一小时一条都没发出去。App 自己每隔几分钟会把手机叫醒一次兜着,但系统对没放行的
   应用有配额,**兜不干净**。这一下比 App 里任何设置都管用。

## 怎么确认下载的没被动过

1.25 的 sha256:

```
4ece31fb2cd7f641a8c7e98fca82d799678009f1c0bbb95d9f93e8d3e7e7c241
```

Windows:

```
certutil -hashfile qq-comment.apk SHA256
```

Mac / Linux:

```
shasum -a 256 qq-comment.apk
```

出来的那串要和上面**一模一样**。不一样就别装。

## 要的权限(一共 6 个)

| 权限 | 干什么的 |
|---|---|
| 网络 | 拉评论池、查更新 |
| 前台服务 + specialUse | 跑的时候不被系统弄死 |
| 唤醒锁 | 跑的时候别息屏睡死 |
| 悬浮窗 | 每个号一个悬浮窗 |
| 通知 | Android 13+ 的前台服务必须能发通知 |

**没有**:短信、通讯录、摄像头、定位、文件访问、安装应用。

## 为什么要 Android 11 以上

**这条线是我们自己定的,不是这个 App 真的需要 11。**
真正卡住的只有三处「量窗口位置 / 量键盘高度」的系统调用,它们是 Android 11 才有的
—— 换成老写法就能下到 **安卓 9**(再往下是真墙:给每个号一份独立的登录信息,
靠的是安卓 9 才开始有的那个接口)。

现在没降,两个原因:一是**不知道有没有人真被它拦着** —— 装不上的人这边一个字都
收不到(装不上 = App 没跑 = 发不出日志);二是真降下去也**只有 beta 那一条跑得起来**,
正式这条还要手机里的浏览器内核支持一个功能,老机器上多半没有。

⚠️ **你要是正被这条线拦着,说一声** —— 有人真需要再动,现在动是凭猜。

⚠️ 版本不够的时候,系统只会含含糊糊说一句(「解析软件包时出现问题」之类),
不会告诉你是版本的事。想确认自己的手机:**设置 → 关于手机 → Android 版本**。

⚠️⚠️ **而「系统版本够」也不等于跑得起来。** 另一道关是手机里那个**浏览器内核**
(WebView)—— 它和系统版本是**两件事**,有些厂商的系统很新、内核却停在好几年前。
内核不够的话,正式版一打开就会在帐号页顶上挂一张红卡告诉你。
这种机器**可以装 beta** —— beta 换了另一个做法(一个号一个进程),**不挑内核**。

## 华为 / 鸿蒙能装吗

**看它底下还是不是安卓。** 判法:**设置 → 关于手机**,里面还有「Android 版本」
这一行就能装。

| | 装得上吗 | |
|---|---|---|
| 鸿蒙 2 / 3 / 4 | **能** | 安卓底子,已经有人在用 |
| 老 EMUI,安卓 10 及以下 | **不能** | 被上面那条 Android 11 挡着(这一类是降得下去的)|
| **鸿蒙 5 / 鸿蒙 NEXT**(纯血鸿蒙)| **不能,也绕不过去** | 安卓那一套整个拿掉了,只认它自己的 `.hap` 安装包 |

⚠️ 鸿蒙 5 / NEXT 这一条**和版本号无关** —— 门槛降到安卓 9 也一样装不上,它压根不收
apk。2024 年底以后买的华为多半是这一种。
⚠️ 网上那些「兼容层」别指望:这个 App 要悬浮窗 + 一直在后台跑,那种环境里起不来。

## 这个仓里有什么

| | |
|---|---|
| Release 附件 | 安装包。Gitee 挂在固定标签 `apk` 下,GitHub 按版本号 |
| `qqcomment/` | App 的**在线更新**文件:`manifest.json` + 几份脚本和界面 |

App 每隔几小时会来这儿看一眼 `qqcomment/manifest.json`。有新版就把文件下到本地,
**逐个核对 sha256**,全部对上才启用,下次启动生效 —— 少一个字节都整批作废。

两个镜像放的是同一份东西:Gitee 排第一(国内通),拉不到会自动换 GitHub。
所以其中一边挂了也不影响更新。

**源码不在这个仓里。** 这里只放发出去的东西。
